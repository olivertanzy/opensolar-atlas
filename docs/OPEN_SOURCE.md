# Open-source readiness and Codex for OSS

Reviewed against the [official program page](https://developers.openai.com/community/codex-for-oss)
on 2026-09-24. Recheck that page before any application; this document is not an
acceptance claim. The application remains paused by the owner.

The program describes support for maintainers of open-source projects, including
six months of ChatGPT Pro for qualifying maintainers. Its criteria focus on
maintainer responsibility, meaningful use and ecosystem value. The official
page also invites explanations of important projects that may not show large
public metrics. A particular framework, language count, attractive demo or
finished repository does not guarantee selection.

## Engineering work in this repository

- Public-benefit scope: a source-attributed educational solar-system explorer.
- MIT original code, separate asset/library notices and per-body evidence links.
- Reproducible data parsers, checksums, unit checks and missing-data policy.
- Vue/native Three.js lifecycle boundaries and a documented extension path.
- Five-language interface and source-qualified scientific descriptions.
- Contribution guide, issue templates, browser checks and static-site build.
